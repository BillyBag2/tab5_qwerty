# tab5_qwerty

This is an arduino project for the M%Stack TAB5. Its a very basic QWERTY
keyboard. At the time of writing it was very much a starter project requiring
more to become something useful.

## Building

Clone the repository and open the .ino file in the arduino IDE. Select the TAB5
as a board, compile and download the code.
